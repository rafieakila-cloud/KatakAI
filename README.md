# Katak AI 🐸 — Kodok terpintar di hutan coding

**Katak AI** adalah PWA (Progressive Web App) dari **Buggames Studio** — belajar coding lewat cerita fantasi **dan** tanya jawab AI yang cerdas, cepat, penuh emoji. **GRATIS tanpa login**, jalan di Android maupun desktop.

## ✨ Fitur

- 👑 **KATAK-1.3** (default) — jagoan koding, cerita fantasi, dan dunia cyber
- 🌐 **KATAK-1** — tokoh dunia & fakta, jawaban bersumber **Wikipedia (bahasa Indonesia)** dengan URL
- 🔑 **Add API models** — pakai key kamu (OpenRouter / Gemini / OpenAI) langsung dari dropdown model di atas layar
- 🐲 **Kurikulum Kodok** — 10 bab cerita fantasi eksklusif + **kuis** + **XP & level** (Berudu → Ksatria Kode) + streak harian
- 💬 Chat streaming, riwayat lokal, mic suara, suara AI membacakan jawaban
- 📎 Kirim foto/file kode, tanya jawab santai penuh emoji 🎉
- 🎨 UI cream Claude + coral dengan animasi penuh, kodok mengetik & melompat
- 🆓 Gratis langsung pakai (model bawaan via Puter — tanpa key/login)

## 📱 Install di Android

Buka https://rafieakila-cloud.github.io/KatakAI/ di Chrome → ⋮ → **Tambahkan ke layar utama / Install aplikasi**.

## ⚖️ Jujur & gratis

Model bawaan KATAK (KATAK-1.3 & KATAK-1) berjalan gratis via **Puter.js** (DeepSeek / GPT-4o-mini) — tanpa key, tanpa login. Kalau Puter penuh, cadangannya Pollinations. Mau lebih pintar: **Koneksi AI** → pilih OpenRouter / Gemini / OpenAI + tempel API key kamu. Katak AI **tidak pernah** berbohong soal identitasnya: ditanya "kamu pakai model apa?", ia jawab jujur.

> Catatan: per 2026, Pollinations membatasi anon dengan captcha, jadi Puter jadi mesin gratis utama.
